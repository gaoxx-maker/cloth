# v0.2 — 京东低频商品补充

搜索结果仍以本地虚拟商品库为主。启用京东来源后，服务端只会对约 10% 的不同搜索词发起一次京东查询，并且：

- 每次搜索最多补充 2 件京东商品；
- 同一搜索词在 60 秒内复用缓存，所有搜索之间也至少间隔 60 秒；
- 京东超时、限流或返回异常时静默降级为虚拟库结果；
- 密钥只从后端 `.env` 读取，绝不发送给浏览器或提交到仓库。

在 `.env` 中设置 `JD_API_KEY`、`JD_API_URL` 后，将 `JD_ENABLED=true`。不同京东 API 产品的搜索参数可能不同，可使用 `JD_API_KEY_PARAM` 与 `JD_QUERY_PARAM` 对齐其文档。
