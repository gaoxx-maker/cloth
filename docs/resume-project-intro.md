# 简历项目简介：Fashion Explorer

## 一句话版本

独立开发服装探索型推荐 Web 应用，基于 FastAPI、PostgreSQL 与 Next.js 搭建从商品数据、行为采集、个性化推荐到多商户价格对比的完整闭环。

## 简历要点版本

- 设计并实现服装探索型推荐系统：基于用户 `impression`、详情浏览和喜欢行为构建偏好画像，结合兴趣、相似度、新颖度、质量与随机性进行可调探索度排序。
- 使用 FastAPI、SQLAlchemy、PostgreSQL 构建分层 REST API，覆盖推荐流、搜索、商品详情、用户行为采集与实验指标统计。
- 使用 Next.js + TypeScript 实现响应式多列瀑布流商品界面、商品详情页和模拟商户页；将喜欢行为放到详情页，实现清晰的交互与埋点边界。
- 构建 1,800 个基础商品 × 3 个模拟商户的 5,400 条报价数据集，支持同款商品的京东/淘宝/拼多多模拟 API 来源、价格对比和跳转落地页。
- 设计真实电商 API 的后端低频接入框架，采用开关、稳定抽样、缓存与冷却时间控制请求量，确保虚拟库作为主数据源并避免泄露密钥到前端。

## 可量化描述

“搭建服装推荐与比价 Web 应用，生成并管理 5,400 条三商户模拟报价数据；实现多因子推荐、用户行为反馈、多列瀑布流展示及商品详情报价聚合。”

## 面试展开说明

项目重点不在于直接爬取电商平台，而是验证服装探索推荐体验：用户可通过探索度调节相关性和新颖度的平衡，系统记录行为并持续更新偏好。多商户报价采用模拟 API 数据源，复现了真实场景中“主商品 + 多来源报价”的数据建模与详情页聚合流程；真实第三方 API 仅可通过后端受控接入。

## 技术栈

Next.js、React、TypeScript、FastAPI、SQLAlchemy、PostgreSQL、Alembic、REST API、行为埋点、推荐排序、A/B 实验指标。
